## 文件类型说明

- `.circ` —— Logisim 电路工程文件，可直接用 **Logisim**（推荐 Logisim 2.7.1 / Logisim-evolution）打开、仿真。
- `.txt` —— 各关卡的操作步骤、连线说明与参考答案记录。

## 使用方法

1. 安装 Logisim：`java -jar logisim.jar`（需 Java 运行环境）。
2. 打开对应目录下的 `.circ` 文件，检查子电路（Subcircuit）是否与头歌关卡要求一致。
3. 结合同目录的 `.txt` 说明理解每条数据通路与微指令设计。
4. 在头歌平台自行搭建、调试，理解原理后再独立完成。

## 学习建议

- 先看「数据表示」与「运算器」，再进入「存储系统」，最后做「单总线 CPU / MIPS / RISC-V」，顺序更顺。
- CPU 设计部分重点关注：指令周期的时序划分、总线数据通路冲突、寄存器堆读写时序、PC 更新时机。
- Cache 关卡注意组相联的标记位、有效位与替换策略实现。
